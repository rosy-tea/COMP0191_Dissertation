# Machine-Learning-Based Materials Screening Using Advanced Featurisation

This repository contains the code accompanying an MSc dissertation completed at University College London.

## Project overview

This project investigates how feature representation and evaluation design affect machine-learning prediction of perovskite solar-cell performance from literature-derived data. Following strict data cleaning, the analyses focus on a cohort of 3,182 devices with recorded current density (Jsc), open-circuit voltage (Voc), fill factor (FF), and power conversion efficiency (PCE).

The study examines three related questions:

1. How sensitive are reported model results to random data partitioning, and how well do models transfer to devices from previously unseen literature sources?
2. Do physically informed representations of materials, device structure, processing, and measurement conditions improve prediction compared with a compact baseline or a larger all-in feature set?
3. Do more structured modelling approaches—including component-specific feature selection, two-stage PCE prediction, alternative model families, and physics-structured kernels—provide a consistent advantage?

The results show that explicit representation of device and layer structure improves prediction over the compact baseline, whereas additional model complexity provides limited further benefit. Performance also decreases under source-aware evaluation, demonstrating that random held-out evaluation can overstate transferability across literature studies.
## Repository contents

### Data preprocessing

- `strict_preprocessing.py`  
  Constructs the strictly cleaned modelling dataset, including checks for layer-stack and thickness inconsistencies.

### Experimental notebooks

1. `notebooks/01_evaluation_stability''.ipynb`  
   Compares repeated cross-validation with repeated random held-out evaluation.

2. `notebooks/02_source_aware_canonical207_fixed_RF.ipynb`  
   Evaluates model transfer to devices from previously unseen DOI sources.

3. `notebooks/03_baseline_feature_expansion_heldout.ipynb`  
   Compares the compact baseline, layer-wise representation, and composition-enhanced representation.

4. `notebooks/04_component_feature_selection_train_only_reselection_audit.ipynb`  
   Performs component-specific feature selection and audits train-only feature reselection.

5. `notebooks/05_PCE_one_stage_vs_two_stage_latest_component_features.ipynb`  
   Compares direct one-stage PCE prediction with a physically structured two-stage approach using predicted Jsc, Voc, and FF.

6. `notebooks/06_similar_device_diagnosis_canonical207.ipynb`  
   Diagnoses unexplained target variation among devices with similar recorded material and device characteristics.

7. `notebooks/07_model_comparison_selected_vs_allin207.ipynb`  
   Compares Random Forest, XGBoost, and multilayer perceptron models using selected and all-in feature representations.

8. `notebooks/08_kernel.ipynb`  
   Evaluates physics-structured custom kernels based on component and feature-framework blocks.

## Execution order

The preprocessing script must be run before the experimental notebooks to construct the local modelling dataset.

Notebook 04 exports the component-specific selected-feature definitions required by notebooks 05, 07, and 08. It should therefore be run before those notebooks.

The notebooks are numbered according to the main experimental workflow, although notebooks 01–03 address separate evaluation and representation questions and may be run independently once the processed dataset is available.

## Data availability

The raw data used in this study were obtained from the [Perovskite Database Project](https://www.perovskitedatabase.com/), described by Jacobsson et al. (2022):

> Jacobsson, T. J. et al. An open-access database and analysis tool for perovskite solar cells based on the FAIR data principles. *Nature Energy*, 7, 107–115 (2022). https://doi.org/10.1038/s41560-021-00941-3

The database is currently accessible through [NOMAD](https://nomad-lab.eu/prod/v1/gui/search/perovskite-solar-cells-database).

The original data snapshot and the processed modelling dataset are not redistributed in this repository. The preprocessing workflow used to construct the study cohort is provided in `strict_preprocessing.py`.

Generated intermediate files, figures, and experiment-output directories are also excluded from version control and can be regenerated by running the relevant notebooks.
